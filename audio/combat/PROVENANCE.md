# ChiArena combat texture library

All eight WAV files were originally authored for this project using
`tools/make-combat-samples.cjs`. They use deterministic granular noise,
resonance, and impact envelopes; no third-party recordings, models, or media
are incorporated. Rebuild with `node tools/make-combat-samples.cjs`.

These original generated samples are dedicated to the public domain under
CC0 1.0. They may be redistributed and modified, including commercially.

44.1 kHz mono, signed 16-bit PCM. Material textures: fire, water, earth, air.
Contact textures: body, guard, whoosh, gravel. Runtime mixes add controlled
pitch variation and the existing procedural layers.
